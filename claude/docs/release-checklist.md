# Claude Yada 发布前人工测试清单

这份清单用于发布前手动检查。每一项都建议在真实 Claude.ai 页面上测试。

## 基础准备

- [ ] 执行 `corepack yarn@1.22.22 build:chrome` 成功。
- [ ] 在 `chrome://extensions/` 重新加载 `dist_chrome`。
- [ ] 刷新 Claude.ai 页面。
- [ ] 打开浏览器 Console，测试过程中留意是否出现红色报错。

## 复制全部

- [ ] 打开一段普通文字对话。
- [ ] 点击“复制全部”。
- [ ] 粘贴结果包含 `# User` 和 `# Claude`。
- [ ] User 和 Claude 顺序正确。
- [ ] 长回复没有明显丢失。

## 选择复制

- [ ] 进入选择模式。
- [ ] 选择几轮对话。
- [ ] 点击“复制选中”。
- [ ] 粘贴结果只包含选中的轮次。
- [ ] 退出选择模式后，选择状态清空。

## 单点选择

- [ ] 在选择模式下点击一个 rail 节点。
- [ ] 该节点变为选中状态。
- [ ] 再点一次同一节点。
- [ ] 该节点取消选中。

## 框选

- [ ] 在选择模式下拖动框选多个 rail 节点。
- [ ] 被框住的节点都能选中。
- [ ] 再次框选已选区域，可以取消对应选择。
- [ ] 框选过程页面不应明显卡顿。

## 反选

- [ ] 先选择一部分轮次。
- [ ] 点击“反选”。
- [ ] 原本选中的取消，原本未选中的被选中。
- [ ] 再复制选中，内容范围符合反选结果。

## 图片摘要

- [ ] User 只发送一张图片时，rail 预览显示 `[图片]`。
- [ ] User 发送文字加一张图片时，显示 `文字摘要 · [图片]`。
- [ ] User 发送两张图片时，显示 `[图片] [图片]`。
- [ ] 一张真实图片不能重复显示成 `[图片] [图片]`。

## PASTED 摘要

- [ ] User 发送 PASTED 文本卡片时，rail 预览显示 `[粘贴内容]`。
- [ ] PASTED 文本卡片不能误显示为 `[图片]`。
- [ ] 文字加 PASTED 时，显示 `文字摘要 · [粘贴内容]`。

## 文件摘要

- [ ] Markdown 文件显示 `[Markdown 文件] 文件名.md`。
- [ ] PDF 文件显示 `[PDF 文件] 文件名.pdf`。
- [ ] CSV 文件显示 `[CSV 文件] 文件名.csv`。
- [ ] 文字加文件时，显示 `文字摘要 · [文件类型] 文件名`。

## 白色模式预览

- [ ] 切换到白色模式。
- [ ] hover rail 节点时，短预览主要显示 User 内容。
- [ ] hover 约 1 秒后，预览展开。
- [ ] 展开后 User 内容显示更多行。

## 橙色模式预览

- [ ] 切换到橙色模式。
- [ ] hover rail 节点时，同时显示 User 和 Claude 摘要。
- [ ] hover 约 1 秒后，User 和 Claude 预览都展开。
- [ ] 选中节点使用橙色高亮。

## 深色模式

- [ ] 切换 Claude.ai 到深色模式。
- [ ] rail 节点可见。
- [ ] hover 预览可读。
- [ ] 选择菜单可读。
- [ ] Counter 可读。

## 导出

- [ ] 点击导出入口。
- [ ] Markdown 导出可用。
- [ ] JSON 导出可用。
- [ ] 导出内容顺序正确。

## Counter

- [ ] Counter 区域正常显示。
- [ ] token 估算正常刷新。
- [ ] 缓存计时显示正常。
- [ ] 5 小时会话用量显示正常。
- [ ] 7 天周用量显示正常。

## 切换对话

- [ ] 从一个 Claude 对话切换到另一个对话。
- [ ] rail 会重新匹配新对话。
- [ ] 选择状态不会错误带到新对话。
- [ ] 复制全部复制的是当前新对话。

## 长对话滚动

- [ ] 打开一段很长的 Claude 对话。
- [ ] 页面滚动时 rail 当前节点能跟随更新。
- [ ] 点击靠前、靠中、靠后的 rail 节点都能跳转。
- [ ] hover 预览不会跑出屏幕。

## Console 红色报错检查

- [ ] 打开 Chrome DevTools。
- [ ] 进入 Console。
- [ ] 刷新 Claude.ai。
- [ ] 执行复制全部、选择复制、框选、反选、导出、切换对话。
- [ ] Console 不应出现 Claude Yada 相关红色报错。
