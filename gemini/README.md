# Gemini Yada v1.6.0

Gemini 网页端三合一增强（gemini.google.com）：

1. 额度实时监控：优先注入 Gemini 输入框内部，轻量显示「5h」和「周」两条进度及 Claude-Yada 风格恢复时间。
2. 透明右侧轮次导航：滚动时用 requestAnimationFrame 实时高亮，不等滚动停止；鼠标悬停时只有当前条显示数字，邻近条递减。
3. Apple Intelligence 风格高亮：导航、选择态和进度条使用青蓝、紫、粉、橙的柔和彩色渐变。
4. 顶部工具条：预览切换按钮是纯透明彩色圆点，复制全部/选择复制是液态玻璃按钮，并带自绘提示。
5. 贴边预览层：预览卡脱离导航条 transform 容器，直接挂在页面顶层，悬停时贴着导航条左侧；`User + Gemini` 模式优先露出 Gemini 回复。
6. 复制全部 / 选择复制：支持一键复制全对话，也支持点选或框选轮次后复制选中内容。

排障：双击右侧导航区域顶部的轮次计数，可生成诊断报告并复制到剪贴板。

## 安装

1. 打开 Chrome → `chrome://extensions` → 开启「开发者模式」
2. 点击「加载已解压的扩展程序」→ 选择本文件夹
3. 打开或刷新 gemini.google.com 的对话页

## 主要交互

- 滚动页面时，右侧导航条会随浏览位置实时高亮。
- 悬停某个短条时，预览卡会出现在该短条正左侧，默认 2 行，驻留后展开到 5 行。
- 顶部彩色圆点只切换预览内容：`User` 或 `User + Gemini`，不改变导航条数量。
- 点击导航短条可跳转到对应轮次。
- 「选择复制」模式下可点选或框选轮次，再复制选中内容。
